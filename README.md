# claire.github.io

Personal site for Claire Jacobs — a hand-drawn, menu-styled page about the things I'm into: commerce, culture, human stories of resilience, art, and technology.

Live at: https://clairejg415.github.io

## Structure

- `index.html` — page content
- `style.css` — hand-drawn "menu" styling (Permanent Marker / Kalam fonts, wavy dividers, doodles)

## Editing

Open `index.html` and replace anything marked `<!-- TODO -->`:

- Bio text in the **About** section
- One-liners for each interest card (Commerce, Culture, Resilience, Art, Technology)
- Project cards and links in **Projects**
- Email / GitHub / LinkedIn links in **Contact**

No build step — it's plain HTML/CSS. Just edit and push to `main`; GitHub Pages redeploys automatically.
